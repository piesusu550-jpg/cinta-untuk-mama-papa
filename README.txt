WEBSITE UNTUK MAMA & PAPA
=========================

CARA MEMBUKA
1. Ekstrak folder ZIP ini.
2. Buka folder "untuk-mama-papa" di laptop.
3. Klik dua kali file index.html untuk membuka website di browser.

CARA MEMASUKKAN FOTO
1. Buka folder images.
2. Salin foto keluarga ke dalam folder tersebut.
3. Untuk halaman kenangan, gunakan nama file ini (atau ubah atribut data-photo di kenangan.html):
   - keluarga.jpg
   - masa-kecil.jpg
   - ulang-tahun.jpg
   - perjalanan.jpg
4. Format JPG/JPEG atau PNG bisa digunakan. Jika nama file diganti, samakan nama di kenangan.html.

Catatan: gambar placeholder.svg dipakai sementara ketika foto pribadi belum dimasukkan.

CARA MENGUBAH TULISAN
- Buka file HTML yang ingin diubah menggunakan VS Code.
- Cari teks yang ingin diganti, lalu ubah teks di antara tag HTML.
- Simpan dengan Ctrl+S (Windows) atau Command+S (Mac).
- Refresh browser untuk melihat perubahan.

CARA MENGUBAH WARNA
- Buka style.css.
- Di bagian paling atas, ubah nilai warna di dalam :root.
- Simpan dan refresh browser.

PENTING UNTUK PRIVASI
- Jangan mengunggah foto atau surat pribadi ke situs publik jika keluarga tidak nyaman.
- Jika memakai GitHub Pages, halaman website yang diterbitkan dapat diakses publik.
- Simpan salinan cadangan folder ini sebelum mengubah banyak hal.

Website ini adalah template statis: tidak memerlukan database, login, atau instalasi framework.
Font Google membutuhkan internet; layout dan konten dasar tetap bisa digunakan saat font gagal dimuat.
